# Reaction-diffusion KAN assessment protocol

This independent dynamical example learns a scalar reaction coefficient
inside a spatial Fisher-KPP model. It uses existing PSM ODE solvers on a
fixed method-of-lines discretization, **not a new PDE solver, PINN, or
operator-learning API**.
The completed results are in
[REACTION-DIFFUSION-ASSESSMENT.md](REACTION-DIFFUSION-ASSESSMENT.md).

## Equation and spatial scheme

```math
\partial_t u = 0.1\,\partial_{xx}u + u(1-u)r(u),
\qquad x\in[0,6],\quad \partial_xu(0,t)=\partial_xu(6,t)=0.
```

The diffusion coefficient and reaction zeros are known. The approximator
represents `r(u)`; the full reaction is `u*(1-u)*p.r(u)`. These fixed factors
do not constrain the sign of the fitted coefficient inside the density
interval.

The default mesh has 24 equal, cell-centred finite-volume cells. Every
interior face contributes equal and opposite diffusive flux to adjacent
cells. Boundary fluxes are zero. Two training profiles are stacked as
48 ODE states sharing one `r`; no face connects their separate spatial
domains.

Initial states are exact cell averages of finite cosine sums, using
`sinc(k/(2n))*cospi(k*(i-0.5)/n)` for mode `k`. This preserves the initial
profiles consistently across mesh refinement rather than mixing centre
samples with cell averages.

## Truths and whole-profile splits

| Case | True coefficient | Full reaction |
|---|---|---|
| `logistic` | `r(u)=1` | `u(1-u)` |
| `crowding` | `r(u)=0.4 + 1.2/(1+9u^2)` | `u(1-u)r(u)` |

Both coefficients are positive on `[0,1]`; the crowding coefficient
decreases with density. The nonlinear case remains KPP-type rather than
introducing an unreported bistable/Allee mechanism.

Writing `C_k=cos(k*pi*x/6)`, the initial profiles are:

| Partition | Profile | Continuum initial field |
|---|---|---|
| Training | `front` | `0.4 + 0.35 C_1` |
| Training | `patches` | `0.4 + 0.22 C_2 - 0.12 C_4` |
| Validation | `mixed` | `0.45 - 0.2 C_1 + 0.12 C_3` |
| Test | `reverse_front` | `0.5 - 0.4 C_1` |
| Test | `fine_scale` | `0.35 + 0.25 C_5` |

All cells are observed at `0:0.25:2.5` for training and validation. Gaussian
measurement noise has standard deviation 0.01, independently drawn for
training and validation. Known initial conditions are not replaced by
noisy observations. Test references are noise-free at `0:0.1:4`, extending
past the training horizon.

Fresh declared seeds are 301--310. Each seed changes observation noise and
neural initialization, not the reference PDE or split. Model initialization
uses seed `20000 + seed`, physical density domain `[0,1]` and the same
constant coefficient 0.8 for every method.

## Comparisons and loss scaling

| Model | Parameters | Representation |
|---|---:|---|
| `spline8` | 8 | Practical natural cubic spline |
| `spline28` | 28 | Parameter-matched natural cubic spline |
| `mlp28` | 28 | One-input, nine-unit tanh MLP |
| `kan_shallow28` | 28 | One cubic KAN edge with 24 grid intervals |
| `kan28` | 28 | Composed 1-2-1 KAN, three grid intervals per layer |

The shared-Adam track uses a 150-iteration ceiling, learning rate 0.03,
and validation selection from `eta=[0,0.1,10,1000]`, applied as
`eta/tr(S)`. A separate native LAML track fits the two conventional splines
with a 25-iteration ceiling and `jac=:forwarddiff`. Native smoothing is
selected internally. No test field or reaction error selects a candidate.

Training weights are `1/(n_cells*n_training_profiles)`. Thus each time's
weighted loss is a spatial/profile mean squared density error, preventing
the raw objective scale from growing merely because more cells are used.
The Gaussian likelihood still accounts for the number of observations;
this normalization is not a claim that a denser noisy observation mesh
contains the same statistical information.

All returned finite candidate coefficients, failures, selected candidates,
timings, cumulative allocations, RHS calls and native diagnostics are
retained. Total tuning time counts all attempted penalty candidates.
The individually selected fit's cost is not the whole model-selection cost.

## Estimands and discretization controls

The primary comparison uses reference data generated by the **same
semidiscrete spatial model** at tight ODE tolerances. This isolates the
approximator/optimizer comparison from spatial model mismatch.

Held-out scores include full space-time field RMSE, coefficient RMSE for
`r(u)`, and reaction RMSE for `u(1-u)r(u)` along the true test fields.
The coefficient is weakly informed near the known zeros, so field error,
coefficient error and full-reaction error must not be conflated.
Reaction error restricted to the training density range and its coverage
are also retained. This is scalar density support, not evidence that all
possible spatial patterns have been identified.

Two test profiles are combined by pooling squared errors within a seed
before reporting medians/IQRs over seeds. Cells and times are not
independent seed replicates. Field and response failures are recorded
separately, and an incomplete profile set is not a complete seed.

`mesh_refinement.csv` is generated separately, before fitting, by solving
the known reaction on 24, 48 and 96 cells and conservatively averaging
fine cells back to the 24-cell mesh. Geometry-only reference measurements:

| Reaction | Test profile | 24-vs-48 cell RMSE | 48-vs-96 cell RMSE, on coarse cells | Ratio |
|---|---|---:|---:|---:|
| Logistic | Reverse front | 1.026e-4 | 2.562e-5 | 4.005 |
| Logistic | Fine scale | 1.143e-3 | 2.833e-4 | 4.035 |
| Crowding | Reverse front | 4.240e-5 | 1.058e-5 | 4.008 |
| Crowding | Fine scale | 8.780e-4 | 2.184e-4 | 4.020 |

The pure-diffusion modal solution also agrees with the semidiscrete
analytic exponential to within `7.59e-13` in the calibration. These
controls establish the intended conservative, second-order spatial
scheme. They do not turn a same-mesh fitting error into a continuum-PDE
accuracy claim.

## Declared runs

Use the environment in [README.md](README.md), new output directories and
serial timed tracks:

```bash
# 400 candidates, 100 selected fits, two test profiles per selection
julia --project=benchmarks/kan --check-bounds=yes benchmarks/kan/reaction_diffusion.jl \
  --output=benchmarks/kan/results/reaction-diffusion-adam

# Separate 40-fit native spline baseline
julia --project=benchmarks/kan --check-bounds=yes benchmarks/kan/reaction_diffusion.jl \
  --track=laml --output=benchmarks/kan/results/reaction-diffusion-laml
```

Options include `--cells`, `--seeds`, `--cases`, `--models`, `--track`,
`--iterations`, `--lr`, `--etas` and `--output`. LAML rejects `--etas`.
The short-budget wiring run uses seed 17 and is not included in the study.
This first spatial assessment does not claim best-attainable performance;
budget and mesh sensitivity remain explicit qualifications.
