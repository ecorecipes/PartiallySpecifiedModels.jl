The vignettes/ directory contains 42 worked examples covering every solver, approximator, and likelihood type. Each vignette is a self-contained Quarto document; the rendered output of each is included in this documentation as a tutorial page, linked below.

Running Vignettes Locally

Each vignette is a Quarto .qmd file that can be rendered locally:

cd vignettes/01_getting_started
quarto render 01_getting_started.qmd --to html

Requires Quarto and a Julia installation with the package dependencies.
